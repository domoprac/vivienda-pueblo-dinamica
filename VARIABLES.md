# Diccionario de Variables del Modelo

| Variable | Tipo | Descripción |
| :--- | :--- | :--- |
| **Stock de Inmuebles** | Nivel | Número de casas en propiedad del ayuntamiento pendientes de reforma. |
| **Presupuesto Semilla** | Nivel | Fondo inicial destinado a la primera promoción. |
| **Tasa de Retorno (Venta)** | Flujo | Velocidad con la que el capital vuelve al ayuntamiento tras una venta. |
| **Efecto Multiplicador Local** | Convertidor | Factor que mide cuánto dinero se queda en el pueblo al contratar empresas locales. |
| **Umbral de Escuela** | Nivel | Mínimo de niños/vecinos necesarios para mantener los servicios abiertos. |
