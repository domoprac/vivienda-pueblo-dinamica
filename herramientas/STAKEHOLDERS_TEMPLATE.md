## 2. Análisis de posición e influencia

Para cada stakeholder, evalúa:
- **Interés** (1-5): grado en que el proyecto afecta a sus objetivos
- **Influencia** (1-5): capacidad de afectar al resultado del proyecto
- **Posición**: Favorable / Neutral / Resistente / Desconocida

| Actor | Interés | Influencia | Posición | Observaciones |
|-------|---------|------------|----------|---------------|
| | | | | |
| | | | | |

### Matriz influencia / posición

```
Alta influencia
        │  GESTIONAR         │  COLABORAR
        │  (neutralizar)     │  (mantener activos)
        ├────────────────────┼────────────────────
        │  MONITORIZAR       │  INFORMAR
        │  (bajo esfuerzo)   │  (mantener informados)
Baja influencia
        Resistente/Neutral        Favorable
```

Clasifica cada actor en el cuadrante correspondiente como guía de estrategia de relación.
