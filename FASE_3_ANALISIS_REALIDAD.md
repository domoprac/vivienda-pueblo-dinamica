## 3.3 Marco de subvenciones aplicables

Santacara es elegible para **tres capas de financiación** combinables:

### Capa 1 — Programa PREE 5000 (municipios de reto demográfico)

Santacara cumple el criterio principal: municipio con menos de 5.000 habitantes en zona de reto demográfico.

| Concepto | Valor |
|----------|-------|
| Programa | PREE 5000 — Real Decreto 691/2021 |
| Gestor en Navarra | Gobierno de Navarra / ORVE Tafalla (~15 min) |
| Objeto | Mejora eficiencia energética envolvente térmica |
| Requisito antigüedad | Más de 25 años (mayoría del parque municipal cumple) |
| Subvención base | Hasta **40% del presupuesto de obra** |
| Subvención máxima | Hasta **65%** con mejora de dos letras energéticas |
| Techo por vivienda | 6.000–7.500 € en envolvente; hasta 25.000 € en áreas preferentes |

### Capa 2 — Rehabilitación Protegida Navarra (programa permanente)

| Concepto | Valor |
|----------|-------|
| Programa | Decreto Foral 61/2013 — vigente y sin límite presupuestario |
| Gestor | ORVE (Oficina de Rehabilitación de Viviendas y Edificios) Tafalla |
| Objeto | Obras de reparación, mejora y adecuación a normativa |
| Requisito antigüedad | Más de 20 años |
| Subvención base | Hasta **40% del presupuesto** |
| Con Proyecto de Intervención Global (PIG) | Hasta **50%**, máx. 7.500 €/vivienda |
| Compatible con PREE 5000 | ✅ Sí — **acumulable** |
| Tramitación | Permanente, sin convocatoria cerrada |

### Capa 3 — Plan de Rehabilitación Rural NASUVINSA

> Dato clave: NASUVINSA tiene **un Plan de Rehabilitación Rural activo** con acuerdos firmados con ayuntamientos navarros para rehabilitar edificios municipales destinados a alquiler. La primera fase incluye 14-15 viviendas en varios municipios con 1,6-1,7 millones de inversión. Bakaiku (Navarra) es referencia de éxito reciente.

| Concepto | Valor |
|----------|-------|
| Programa | Plan de Rehabilitación Rural NASUVINSA |
| Objeto | Rehabilitación de edificios municipales para alquiler joven / asequible |
| Modelo | Convenio ayuntamiento + NASUVINSA; gestión posterior vía Bolsa de Alquiler |
| Financiación | NASUVINSA cofinancia la obra; ayuntamiento aporta el inmueble |
| Subvención adicional | Compatible con PREE 5000 y Rehabilitación Protegida |
| Ventaja | Reduce coste neto municipal a **0-20% del presupuesto de obra** |
| Acción requerida | Contacto con NASUVINSA (oficina Tafalla) para iniciar convenio |

### Capa 4 — NextGenerationEU / PRTR (rehabilitación energética edificios)

| Concepto | Valor |
|----------|-------|
| Programa | PRTR — Plan de Recuperación, Transformación y Resiliencia |
| Objeto | Rehabilitación energética con reducción acreditada de consumo |
| Subvención | 40–80% del presupuesto según nivel de mejora energética |
| Deducción IRPF adicional | Hasta 60% de la parte no subvencionada |
| Estado convocatoria | Activo; gestionado por ORVE autonómica |

### Resumen de combinación óptima

| Escenario | Subvención total estimada | Coste neto ayuntamiento |
|-----------|--------------------------|------------------------|
| Solo Rehabilitación Protegida | 40% | 60% |
| PREE 5000 + Rehabilitación Protegida | 55–65% | 35–45% |
| Plan Rural NASUVINSA + PREE 5000 | 75–85% | 15–25% |
| Plan Rural NASUVINSA + PREE 5000 + PRTR | **80–90%** | **10–20%** |

**Conclusión**: con la combinación óptima, el ayuntamiento puede rehabilitar una vivienda invirtiendo entre el 10% y el 20% del coste de obra, recuperando esa inversión vía ingresos de alquiler en 3-6 años.

**Acción inmediata recomendada**: contactar con la oficina NASUVINSA Tafalla para adherirse al programa ELENA — es gratuito y proporciona el apoyo técnico para realizar el inventario de activos (sección 3.2) y diseñar la primera operación piloto.

### Sensibilidad del modelo

| Variable | Escenario pesimista | Escenario base | Escenario optimista |
|----------|---------------------|----------------|---------------------|
| Subvención real | 55% | 75% | 85% |

Incluso en el escenario pesimista (55% subvención, 400 €/mes), el modelo es viable en menos de 7 años con coste inicial inferior a lo que costó el Centro Sociocultural 2026 (355.000 €).
